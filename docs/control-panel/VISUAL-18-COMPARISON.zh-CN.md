## 截图范围

D:/KDEBuild/unified18-visual/desktop 中新增二十四张整页/弹窗图：每个尺寸四个入口、五种当前表盘、设置和确认弹窗、按钮编辑表单。底色使用与 Main.qml 相同的 #f5f7fb。测试加载的是 ControlDashboard.qml 根组件，不含原生标题栏；连接按钮只核对 openConnections 信号，不打开原生设备管理窗口，关于页源码按钮未点击启动浏览器。

D:/KDEBuild/unified18-visual/ui 和 after-fix/ui 保存真实 AVD 的五类画面；每次独立 XML 和 PNG 由对应日志 JSON 引用。Android 测试临时使用 zh-CN 应用语言，结束恢复原空语言列表。模拟器按其系统 UTC 显示本地时间，Windows 按宿主时区显示；不是把时钟读数硬编码成相同值。

Android/Qt 的本地渲染还使用 logs/live-observation.json 中已取得的 Open-Meteo 快照；其来源和时间保留，不是随机或伪造天气。合成的布局单测样本明确只用于测试，不打入产品。
